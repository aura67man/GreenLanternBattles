# Last One Standing

A text-based survival roleplay simulator in one self-contained `index.html` (vanilla JS, Canvas, no libraries). Open it in any modern browser.

Pick a world, enter your cast (names + genders), and watch randomly generated fights, deaths, alliances, romances and betrayals play out day by day, ending in a victor or a happy, bittersweet or tragic ending.

Worlds: The Hunger Games, The Maze Runner, Attack on Titan, Squid Game, The Walking Dead, Stranger Things, The Last of Us, Game of Thrones, Alice in Borderland, Jurassic Park.

Fan-made; all franchises belong to their respective owners.

## Royal Chip Casino (`casino.html`)

A play-money casino in one self-contained `casino.html` (vanilla JS, Canvas, no libraries). You start with $1,000 in chips; lose them all and you start over.

Games: Blackjack, Casino Hold'em, Lucky Sevens slots, Roulette, Craps, Rocket Crash and Baccarat. Each game has a rules screen before you sit down, and you can reopen it from the RULES button.

## J.A.R.V.I.S. (`jarvis.html`)

An Iron Man-style voice assistant in one self-contained `jarvis.html` (vanilla JS, Canvas, no libraries). Open it in Chrome or Edge for voice input; other browsers can still type.

Click the arc reactor, press MIC or press Space to talk, or turn on the "Jarvis" wake word. He answers out loud with a British voice.

Built-in skills (no key needed): time and date, live weather (Open-Meteo plus your location), timers and reminders, notes, maths, web search, opening sites, coin flips, dice, battery and status reports, and a few suit protocols.

For open conversation, paste an Anthropic API key in AI Core Settings. The key is kept only in your browser's local storage and sent only to api.anthropic.com, so don't use it on a shared computer.
